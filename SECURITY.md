# Security policy

## Reporting a vulnerability

Please do not report a vulnerability in a public issue or discussion.

Use GitHub's "Report a vulnerability" button on the Security tab of this repository. It opens a private
advisory that only the maintainers can read. If the button is not shown, open an issue that asks for a private
contact and leave out every detail of the problem.

Describe what you tested, how to repeat it and what you saw. Leave out other people's data, passwords and keys.

We aim to confirm receipt, look into the report and tell you when a fix is out. This is a small team, so there is
no fixed response time. With your permission we credit you.
